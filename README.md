# danved.dev

Static site for https://danved.dev, served by GitHub Pages from the `master` branch root.

- `index.html` – home page (edit the Projects cards to taste)
- `404.html` – not-found page
- `CNAME` – custom domain for GitHub Pages (keep this file)
- `.nojekyll` – serve files as-is, no Jekyll build

DNS is on Cloudflare; see the setup notes in the PR that added this.
